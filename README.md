# Wispwood — Magical Creature Rescue

Original mobile-friendly **2D Merge + Rescue** browser game prototype, with no paid AI API or game server.

## Play
Open [index.html](./index.html) using a browser or deploy as a static web page.

1. Tap **Gather magic** to spawn an item.
2. Tap or drag two matching items to merge them.
3. Create a **Herb**, **Elixir**, and **Crystal** and deliver each to Mivra.
4. Rescue Mivra and open the next path.

Progress is stored in browser localStorage.

## MVP
- 6×6 merge board; three crafting chains; rescue dialogue; responsive desktop/mobile interface.
- Original SVG creature illustration and CSS motion.
- One rescue chapter. No ads, payment, multiplayer, accounts, or AI calls while playing.
- This is a **prototype**, not a finished commercial game.

## Roadmap
1. Playtest the merge loop and rescue reward with real users.
2. Improve 2D animation, character art, audio and accessibility.
3. Add original creature collection and exploration after retention is validated.
4. Evaluate monetization and platform rules before release.

## IP review
**Wispwood** and **Mivra** are working names; trademark availability is not yet confirmed. Review artwork, emoji, music and font licensing before commercial distribution. Do not copy other games' character designs, interface artwork or branded worlds.
